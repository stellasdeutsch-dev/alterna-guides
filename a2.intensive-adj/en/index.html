Rule

How to build the flash

kıpkırmızı
kı + p + kırmızı = kıpkırmızı
  1. 1Take a word: kırmızı.
  2. 2Cut off the start up to the first vowel: kı.
  3. 3Stick on one consonant: m, p, r or s.
  4. 4Put it in front of the word. As one word, no hyphen.

Four steps, all mechanical. You only have to think in the third: which consonant to take. More on that next.

Memory trick

Which consonant?

There's no rule. Turks just say it that way. Learn them in pairs, like a song. Most often it's p and m, while r and s are rare guests.
