03
закон

Закон: гласные не дружат

Турецкое слово растёт хвостами. Хвост липнет к концу слова.

Слово кончается на гласную. Хвост начинается с гласной. Получается araba + a. Две a лоб в лоб.

Турецкий этого не выносит. Он ставит между ними согласную. Мост.

arabaya

Слово на согласную моста не ждёт: ev + e = eve.

Где нужен мост?

Мост y — для всех

Y — рабочая лошадка. Пашет почти везде. Без него вышло бы araba-a. Звучит как икота. У него три клиента.

Нажми на слово: сначала услышишь его без моста, потом с мостом.

-(y)A

Скобки в -(y)A значат: y приходит по вызову. Слово на согласную? Моста нет: okula, evi.

06
мост s

Мост s — только для своих

S — мост частный. Пускает только «его» и «её». Без него вышло бы kapıı. Две ı подряд — как два таксиста в одной полосе.

Хвост -(s)I значит «его, её». После гласной встаёт s: arabası. После согласной моста нет: evi.

Ещё s склеивает названия. Две вещи — одно имя: Türk kahvesi, çay bahçesi.

«Его комната» — это…

nnnnnn
07
мост n

Мост n — второй этаж

N строится на s. Слово уже «его»: arabası. Теперь его надо куда-то везти. Запомни картинку: s — первый этаж, n — второй.

Добавляешь -a. Опять две гласные. Но y сюда не пускают. Встаёт n: arabasına.

arabasına

Второй дом n — o, bu, şu. Тут n ставят и без всякого «его»: ona, onu, buna.

«В его комнату» — это…

Стамбул подписан мостами

Башня, мост, пристань, проспект. В названиях Стамбула s живёт на каждом шагу. Нажимай на точки. Так турки подписывают всё, что чьё-то: башня Галаты, пристань Кадыкёя.

12
сравни

Русский, турецкий, казахский

В русском «его» — отдельное слово. Гласным негде столкнуться.

В турецком всё в одном слове. Хвосты стоят плотно, как пассажиры на пароме в час пик.

в машину
его машина
в его машину

Знаешь казахский? Там те же s и n: арбасы, арбасына. Даже машина почти та же.

Запомни тремя словами

Y — для всех. S — «своё». N — «несу своё».

Своё — это «его, её». Несу — значит, к своему цепляешь ещё хвост: arabasına.
